# ROOM-MANAGEMENT-SYSTEMS

 room management systems built with:
 - `backend`: Express + TypeScript + PostgreSQL + Prisma 7
- `frontend`: React + Vite

ALL RUN ON BUN

## FRONTEND
### TECH STACK
- React
- Vite
- ESLint
- Javascript
### Installation
make sure you are in the frontend directory:
```bash
cd frontend
```
install the npm:
```bash
npm run dev
```
the web should be at:
```bash
http://localhost:5173/
```


## BACKEND:

### TECH STACK:
- Bun 1.3.11
- Express
- TypeScript
- PostgreSQL 18
- Prisma7
- WebSocket for real-time room rendering and notifications

### PREQUISITIES
Before running the project, make sure you have installed:

- Bun 1.3.11 or newer
- PostgreSQL 18 or newer
- Git
- Optional: Docker and Docker Compose

check Bun version:
```bash
bun -v
```
check postgresql:
```bash
psql --version
```

### 1. Clone the Repository
```bash
git clone https://github.com/FuTour-App/room-management-system 
cd backend-express
```
If the repository is already available locally:
```bash
cd backend-express
```
